Biomedical graph RAG

Ask the graph. Understand the answer.

RAGnosis is a text-only biomedical assistant. It retrieves related entities from a remote Neo4j Aura knowledge graph, then Cohere writes a follow-up or advice reply from that context.

Open diagnosis Read the architecture

What it does

A chat that looks up the graph before it speaks.

You describe symptoms in the browser. Flask posts that turn, plus the on-page transcript, to POST /chat. The server searches Neo4j Aura, then asks Cohere to reply using the retrieved properties and the conversation so far.

The live production path is keyword retrieval, not vector search. Matching uses Cypher CONTAINS over name, text, description, disease, symptom, title, and canonical_name, limited to five nodes. Embedding fields are stripped before context is sent to the model.

Production

What is deployed

The Render web service is Flask, remote Neo4j Aura, Cohere Chat, and this HTML UI. gunicorn binds 0.0.0.0 and the host-provided PORT. GET /health reports process liveness even when Aura or Cohere is down. /chat returns the real retrieval or generation error instead of a fabricated answer.

This deployment is text chat only. Voice input, speech synthesis, Gradio, image upload, and notebook-only RAG variants are not part of the production path.

About

A retrieval-augmented biomedical assistant, documented as it actually runs.

Medical questions are easy to answer fluently and hard to ground. RAGnosis separates lookup from language: Neo4j Aura supplies a small set of related graph entities, then Cohere writes the reply. The assistant is informational. It is not a licensed clinician and it does not replace diagnosis or treatment.

The problem

A language model alone can sound medical without being tied to a maintained knowledge base. RAGnosis keeps the knowledge in a graph you can query, then asks the model to stay inside that context when it is present, and to say so when it is missing.

Why a knowledge graph

Entities such as symptoms, diseases, and related descriptions sit as nodes with properties. A Cypher lookup can return those properties as structured context. Production retrieval is property-level keyword matching, not a claim of live vector search.

Neo4j Aura

Credentials come from NEO4J_URI, NEO4J_USER, NEO4J_PASSWORD, and NEO4J_DATABASE. The driver connects lazily. If Aura is paused or unconfigured, the UI and /health still respond. Search looks at name, text, description, disease, symptom, title, and canonical_name.

Cohere

COHERE_API_KEY is read from the environment. Generation uses cohere.Client Chat at temperature 0.4. A missing key or API error is returned to the user. The app does not invent a diagnosis when Cohere is unavailable.

Deployed today

Render Web Service, runtime Python 3.11, build pip install -r requirements.txt, start gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --timeout 120, health check GET /health. Render injects PORT. The Free plan has no GPU and may sleep after about 15 minutes idle.

Experimental / research

experiments/ holds Colab RAG notebooks and graph construction exports. Those artifacts may use other LLM backends or retrieval strategies. scripts/doctor_chatbot.py is a terminal counterpart. scripts/EmbeddingsIngestion.py writes SIMILAR_TO links from Database/EnrichmentReport. Engineering decisions

Secrets stay in environment variables. The process starts without Aura. /health remains 200 when dependencies are down. /chat fails closed with a redacted error. Conversation history stays in the browser because the Render Free filesystem is ephemeral. Retrieved embedding vectors are dropped so the model sees text properties, not raw vectors.

Limitations

Keyword CONTAINS is not semantic search. Five nodes is a small context window. Offline files in Database/ do not equal the live Aura contents. Experimental voice, image, or vector-RAG work is not claimed here. Older Git history on the GitHub repository may still contain leaked credentials; treat those values as compromised.

Retrieval

How lookup works

Each message is searched in Neo4j Aura with case-insensitive CONTAINS on selected properties. At most five nodes come back. Those properties, without embedding vectors, are passed to Cohere with the current transcript.
